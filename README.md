🐉 드래곤 점프 피하기 (Dragon Jump)
간단한 조작으로 즐기는 원버튼 점프 액션 웹 게임입니다. 아기 드래곤이 되어 장애물을 피하고, 음식 아이템을 먹어 전설의 드래곤으로 성장하세요!

🎮 게임 소개
장르: 캐주얼 아케이드 / 점프 액션

플랫폼: 웹 브라우저 (HTML5)

플레이 시간: 1판 30초

핵심 재미: 점프 회피 → 음식 먹고 성장 → 10단계 전설 드래곤 달성

⌨️ 조작 방법
키	동작
Space	점프 (지면에서 1단, 공중에서 최대 3단 점프 가능)
P	일시정지 / 재개
R	다시 시작
💡 3단 점프 규칙: 1단은 기본 높이, 2단은 1단의 약 1/2, 3단은 1단의 약 1/3만큼 추가로 상승합니다.

🎯 게임 규칙
30초 동안 생존하면 승리!

장애물에 부딪히면 목숨 1개 감소 (최대 3개)

음식 아이템을 먹으면 드래곤이 1단계 성장 (최대 10단계)

장애물에 부딪히면 성장 단계가 1단계 후퇴

하트십자가 물약을 먹으면 목숨 1개 회복 (단, 충돌 후 3초 뒤에 등장)

🐲 드래곤 성장 단계 (10단계)
단계	이름	특징
1단계	아기 드래곤	가장 작은 크기
2~3단계	어린 / 성인 드래곤	뿔이 자라남
4~5단계	숙련 / 장로 드래곤	꼬리, 날개 생성
6~8단계	고대 / 신화 / 전설 드래곤	수염, 발광 효과
9단계	화염 드래곤	입에서 불꽃이 나옴
10단계	여의주 드래곤	여의주 2개가 주변을 회전
🍔 아이템 종류
음식 아이템 (🍎🍔🍗🍰🍚...): 과일, 채소, 고기, 패스트푸드, 디저트 등 45종의 이모지가 랜덤하게 등장합니다. 먹으면 성장합니다.

하트십자가 물약 (❤️➕): 장애물에 부딪힌 뒤 약 3초 후 등장합니다. 먹으면 목숨을 1개 회복합니다.

⚙️ 난이도 설정
난이도	특징
착한 맛	장애물이 나오지 않는 연습 모드 (아이템만 등장)
중간 맛	1~2개의 장애물 그룹, 기본 난이도
붉닭 맛	1~3개의 장애물 그룹, 가장 어려운 난이도

📊 데이터 기반 난이도 조정 (Why?)
이 게임은 실제 플레이 데이터를 기반으로 난이도를 조정했습니다. (CSV 기록 비교)

변경 전 (Before): 10회 플레이 결과 전패(0승 10패), 10회 모두 "초반 충돌" 로 사망 (생존 시간 3~9초). 게임이 성립하지 않는 수준의 난이도였습니다.

변경 후 (After): 승률 40% 로 상승, 실패 원인이 중반으로 분산되었으며, 최대 10단계 진화 달성에 성공했습니다.

결론: 초반 난이도를 완화하고, 속도를 통일(0.30)하며, 착한 맛의 장애물을 제거하여 "조작이 단순하고 실패 원인이 명확한 게임" 을 만들기 위해 조정했습니다.
